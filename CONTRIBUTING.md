# Contributing

Thank you for your interest in contributing!

We welcome contributions of all kinds, including code, documentation, ideas, bug reports, and infrastructure improvements.  
We have made it as easy as possible to contribute too!

## Getting Started

1. Fork the repository
2. Make your changes
3. Submit a pull request
4. Wait for review and feedback
